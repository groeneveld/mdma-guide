# Capitalization protection word list for fix_bib.py
#
# One term per line. Blank lines and lines starting with '#' are ignored.
# A term may be a single word ("Stanford") or a multi-word phrase ("New York").
#
# How it is used: after a title is title-cased, every occurrence of a term
# below is wrapped in curly braces using EXACTLY the casing written here, so a
# sentence-casing bibliography style can't lowercase it (mdma -> {MDMA},
# stanford -> {Stanford}). Matching is case-insensitive, with one guard: an
# all-lowercase occurrence of a term that is also an ordinary English word
# (per the system word list) is left alone, so the pronoun "us" never becomes
# "{US}" while "US" / "USA" still do. Acronyms not listed here are still
# protected automatically by the >=2-uppercase-letters rule in fix_bib.py;
# this file exists to (a) pin canonical casing for mixed-case terms
# (CBTp, CYP2D6, ICD-11) and (b) cover proper nouns the acronym rule misses.
#
# Add a line whenever a new name/acronym should stay capitalized.
